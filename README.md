# 墨尺 · 网文质检

> 量文字的尺。检测中文网文的"AI 味"，**满分 10 分、越高越不像 AI**，对标预置基准。

## 启动

```bash
git clone https://github.com/yycqyjq/mochi-ruler.git
cd mochi-ruler
python3 server.py            # 默认 http://127.0.0.1:8765
python3 server.py 9000       # 指定端口
```

**零依赖** —— 只用 Python 标准库，不需要 pip install。

## 怎么用

1. 打开 `http://127.0.0.1:8765`
2. 左侧粘贴正文，或点「选文件」载入 `.txt` / `.md` / `.markdown`
3. 也可以点「选文件夹」载入整个文件夹，或把文件/文件夹直接拖进**同一个输入框**
4. 也支持从桌面复制文件/文件夹后，在输入框里直接 `⌘V` 粘贴
5. 拖入/粘贴文件夹后，输入框上方显示 `📁 文件夹名 · N 个文本文件`，输入框保持空白，正文在后台分析，不把整本内容铺满输入框
6. 文件夹和输入框可以同时有内容，点击检测时会**合并两部分内容**
7. 鼠标悬停文件夹标签可查看：文件数、格式、总字数、识别章节数、跳过数量；点 × 可移除文件夹，输入框手动内容保留
8. 不支持的格式会弹窗提示并跳过
9. 点「开始检测」（或 `Cmd+Enter`）
10. 右侧出结果

## 文件来源标签与检测状态

选中文件、文件夹，或从桌面粘贴文件后，都会在输入框上方挂一个来源标签：

- 文件：`📄 文件名 · 1 个文本文件`
- 文件夹：`📁 文件夹名 · N 个文本文件`
- 鼠标悬停：查看格式、总字数、识别章节、跳过文件等信息
- 点 ×：移除来源，但保留输入框手动补充的内容
- 点击检测：按钮变为「检测中…」并显示转圈，完成后自动恢复

如果文件来源和输入框都有内容，检测时会合并两部分。

## 自动拆章节

单文件、文件夹和输入框文字都使用同一套章节识别规则，支持：

- Markdown：`# 第一章 标题`
- 中文章号：`第一章 标题`
- 数字序号：`1、标题`
- 纯数字前缀：`01开篇` / `02 别离`（数字紧跟标题，导出 txt 里很常见）
- 英文章号：`Chapter 1`
- 特殊章节：`楔子` / `序章` / `番外`

> 「纯数字前缀」这类章头没有任何显式分隔符，最容易误伤，所以加了四重护栏：该行前面必须是空行、数字 1–4 位、数字后紧跟汉字、整行 ≤24 字且不能是「2012年」这类时间。实测在长篇网文与 AI 语料上，只有原本就拆不开的那一份被修正，其余文件结果逐字不变。

载入后会提示识别到的章节数；点击检测时后端再次按同一规则拆分，前后端口径一致。

## 看什么

**所有分数都是 0–10 分，越高越好**（越高越不像 AI 网文）。标杆 = 预置基准值。

### 分数卡（总分 + 五维）

| 分数 | 说明 | 标杆 |
|---|---|---|
| **总分** | 五维等权平均（各 1/5） | 8.48 |
| **真人感** | 反转句 / 模糊语 / 破折号 / 加粗 … 越少越高 | 9.63 |
| **人味** | 口语 / 对话占比 / 情绪外显 / 叠词 | 9.75 |
| **代入感** | 感知 / 认知 / 身体 / 受限 | 4.84 |
| **节奏** | 长句 p90 / 短句 p10 / 段长 CV / 书面虚词 | 8.71 |
| **句法** | 代词密度 / 代词起句率 / 句长中位 / 转折连词 | 9.50 |

**低 AI 味 ≠ 有人味。** 两个维度要一起看。

### 逐项对比

每项给三个数：**你的分 / 标杆 / 判定**，都是 0–10 分。鼠标悬停指标名可看该指标的**原始值**（如「破折号收束 6.0/千字」）。

- **达标** = 与标杆持平或更好（差距 ≤0.5 分）
- **接近** = 略低于标杆（差 0.5–2 分），可留意
- **偏低** = 明显低于标杆（差 >2 分），通常是 AI 特征

因为全表统一「越高越好」，所以**没有方向栏**——不用记哪个指标是"越低越好"。

### 逐章列表

按 Markdown 的 `# 第N章 标题` 自动分章。每章一行，列出**真人感 / 人味 / 代入 / 节奏 / 句法 / 总分**，附违规项。

## 基准来自哪

**内置一组预置基准值**，来自对中文长篇的逐章统计：每本全书等距抽样（单章 ≥1200 字，每本至多 100 章），先算各本中位，再取跨本中位。

基准覆盖 **24 本**（语料里剔除了两本不可用的：一本整本没拆出章节，一本章均近万字疑似合章）。

基准只以**匿名代号**形式存在，**具体书目不入库** —— 代码、配置、文档里都不出现作品名。

**基准只存原始指标，不存分数。** 五维分在运行时用当前公式从原始指标算出来。这样公式一改（新增指标、调整权重、撤编维度），基准口径自动跟着走，不会出现「基准是旧公式算的、被测文本是新公式算的」这种对不上的情况。

## 指标说明

逐项对比表展示 **38 项**指标，每项 0–10 分。

分数怎么算：每个指标配一对「达标值 / 超标值」，达标值得 **10** 分、超标值得 **0** 分，中间线性折算（`good()`）。五维分是该维各指标逐项分的加权平均，总分是五维等权平均。全库只有这一套口径——**0–10，越高越不像 AI 网文**。

**最强的一组是「句法」维**（2026-09-13 新增）。用真人长篇与 AI 文本逐章实测，这几项的区分度远高于人工罗列的「AI 俗套词表」：

| 指标 | 真人长篇 | AI 文本 | 说明 |
|---|---|---|---|
| 第三人称代词（次/千字） | 2.16–16.19（中位 9.85） | 17.84–30.86（中位 28.71） | **两边完全不重叠，AUC = 1.00** |
| 代词起句率 | 0.000–0.070（中位 0.024） | 0.082–0.153（中位 0.145） | **两边完全不重叠，AUC = 1.00** |
| 句长中位（字） | 16–71（中位 30） | 8–18.5（中位 15） | AI 系统性短句化，AUC 0.96 |
| 转折连词（次/千字） | 0.31–7.68（中位 2.62） | 0.00–1.22（中位 0.10） | **AUC 0.989，与其余三项相关 ≤0.17** |

两个「完全不重叠」背后是同一件事：**AI 不肯换主语**——不写人名、不用称谓、不省略，全靠「他 / 她 / 它」把每一句顶住；同时把句子写短。这两点用人眼很难察觉，用尺子一量却异常干净。

第四项是另一回事：**AI 几乎不写转折**。「但是 / 可是 / 不过 / 然而 / 却 / 反倒 / 反而」，真人长篇每千字 2.6 次，AI 每千字 0.1 次——差 26 倍。AI 的叙事是一句接一句地平铺，不会回头推翻前一句。

> **口径教训：密度型与比值型都可能被「短句化」污染，必须做残差检验。** 每千字密度会被短句化**虚高**（AI 句子短 → 每千字句子多 → 任何「X/千字」都跟着涨）；每百句比值则会被**句长绑架**（句子越长，每句撞上目标词的概率越高，X/百句 ≈ 常数 × 句长）。所以在入库前一律过这一关：**在真人样本上做 `X ~ 句长中位` 回归，再看 AI 残差的 AUC**。`g_turn` 用每千字口径，残差 AUC = 0.990（独立信号）；同期候选 `oral_modal`（语气词/百句）残差 AUC 只有 0.183——方向还反转了，说明它只是句长的回声，因此**没有入库**。

**标点类也稳定**（下面是原始值：标杆为 0，看到就是问题）：

| 指标 | 标杆 | AI 文 |
|---|---|---|
| 破折号收束 | 0.00 | 6.64 |
| 否定-破折号纠正 | 0.00 | 0.59 |
| 反转句（不是A是B）| 0.00 | 0.67 |
| 罗列排比 | 0.00 | 1.39 |

> **实测反例，别再往词表里加这些词。** 「心中一凛 / 嘴角勾起 / 不禁 / 下意识 / 某种 / 莫名 / 眼神」这类手写「AI 俗套词表」**没有区分力**：真人长篇与 AI 文本的两端中位都是 0，AUC 只有 0.38–0.60。AI 不用它们，真人（这批）也不用了。

> **`词汇多样性`（ttr）与 `动作密度`（act）已于 2026-09-13 退出打分。** 原因：ttr 在真人 / AI 两档上完全重叠（有一篇 AI 的 ttr 还是全体最高）；act 的方向与直觉相反——AI 文本的动作密度反而**更高**，按「越高越好」给分等于奖励 AI。两个原始值仍在后台照常计算，供对照，只是不再计分、不再展示。

## 边界

**这是"读感 lint"，不是"检测规避工具"。**

- 检测已知的 AI 句式与标点，目标是**读感**
- 外部 AIGC 检测平台只作参考，**不承诺通过任何检测**
- 适用范围：**中文长篇网文**。不适用于议论文 / 短篇 / 营销文案

## 自己体检：这把尺子还准吗

`tools/audit.py` 是开发工具，不参与服务运行。它对全部指标逐项体检，回答「哪些指标还有效、哪些已经成了摆设」：

```bash
python3 tools/audit.py --human <真人语料> --ai <AI语料> [--ref <参照组>]
```

- **真人组**是判据的正样本，**AI 组**是负样本
- **参照组**是已知标签的对照组，只做对照展示和误判提示，**不进任何判据**。典型用法：把自己写的正文挂上去，看它落在哪一侧

每个指标给出四件事：分布、**分离度**（= 2×|AUC−0.5|，方向无关）、**残差分离度**（控制句长后，用来识破「短句化」的回声）、**两侧满分率**（≥95% 就是扣不动分的死项）。

> **口径教训，改指标前必看。** 「每千字」会被短句化虚高（AI 句子短 → 每千字句子多 → 什么密度都涨）；「每百句」会被句长绑架（句子越长，每句撞上目标词的概率越高，`X/百句 ≈ 常数 × 句长`）。所以一律加做残差检验：在真人样本上做 `X ~ 句长中位` 回归，再看 AI 残差的分离度。真信号残差仍在，句长的回声会掉下来甚至方向反转。
