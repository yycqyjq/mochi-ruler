# 墨尺 · 网文质检

> 量文字的尺。检测中文网文的「AI 味」——**满分 10 分，越高越不像 AI**。

墨尺是一个跑在本机的**中文网文「读感 lint」**。它把正文拆成章节，逐项量出那些「读起来像机器写的」特征：代词是不是过密、句子是不是被切得太碎、有没有把感官写成分镜脚本、人物有没有真正在「想」。然后折算成 0–10 分，与内置的真人长篇基准对照，**指出最该先改的项**。

它**不是** AIGC 检测规避工具。墨尺只关心读感，不承诺通过任何外部检测平台。详见 [设计取舍](#设计取舍)。

- **全程本地** —— 只监听 `127.0.0.1`，正文不出本机
- **零依赖** —— 只用 Python 标准库，不需要 `pip install`
- **39 项指标** —— 每项都配口径说明与真人基准
- **只读** —— 不修改你的文件，只出报告
- **开箱即用** —— 起一个进程，浏览器打开就能用

## 特性

- **五维评分**：真人感 / 人味 / 代入感 / 节奏 / 句法，各占 1/5，合出总分（0–10，越高越好）
- **逐项对比**：39 项指标逐一给出「你的分 / 标杆 / 判定」，每项带 `?` 口径说明与原始值
- **完整对照表**：明暗主题、按维度筛选、逐章列表与违规项
- **多来源输入**：粘贴、选文件、选文件夹、拖拽、`⌘V` 剪贴板粘贴，可混用并自动合并
- **自动拆章**：同时识别 Markdown 标题、中文章号、「第X集 卷名 第X章」两级章头、数字序号、纯数字前缀、英文章号与「楔子/序章/番外」
- **合规硬规则**：圆括号注记、违禁元词、破折号超限、正文加粗、章内重复、章末抒情等，命中即列为违规项
- **内置体检工具**：`tools/audit.py` 可对全部指标做区分度体检，回答「哪些指标还有效」（见 [开发工具：全指标体检](#开发工具全指标体检)）

## 环境要求

- **Python 3.9 或更高**（已实测 3.9.6 与 3.13）
- 任意现代浏览器

不需要任何第三方包，也不需要虚拟环境。

## 快速开始

### 获取与启动

```bash
git clone https://github.com/yycqyjq/mochi-ruler.git
cd mochi-ruler
python3 server.py            # 默认 http://127.0.0.1:8765
```

指定端口：

```bash
python3 server.py 9000
```

终端会打印访问地址。按 `Ctrl+C` 停止。

### 用法

1. 打开 `http://127.0.0.1:8765`
2. 在左侧任意一种方式载入正文：
   - 直接在输入框**粘贴**文本
   - 点「**选文件**」载入 `.txt` / `.md` / `.markdown`
   - 点「**选文件夹**」载入整个文件夹
   - 把文件或文件夹**拖进输入框**
   - 从桌面复制文件或文件夹后，在输入框里 `⌘V` 粘贴
3. 载入文件夹后，输入框上方会出现来源标签（`📁 文件夹名 · N 个文本文件`），鼠标悬停可看格式、总字数、识别章节数与跳过数量；点 `×` 移除来源，输入框里的手动内容会保留
4. 文件夹与输入框**可以同时有内容**，检测时会合并
5. 点「**开始检测**」（或 `⌘/Ctrl + Enter`）
6. 右侧出结果

不支持的格式会弹窗提示并跳过。

## 结果怎么看

**所有分数都是 0–10，越高越好**（越高越不像 AI 网文）。「标杆」= 内置预置基准值。

### 分数卡（总分 + 五维）

| 分数       | 说明                                                     | 标杆 |
| ---------- | -------------------------------------------------------- | ---- |
| **总分**   | 五维等权平均（各 1/5）                                   | 8.89 |
| **真人感** | 反转句 / 模糊语 / 破折号 / 古典指示词 …                  | 9.57 |
| **人味**   | 口语 / 对话句长 / 情绪外显 / 情绪词种类 / 叠词 / 疑问句 | 8.51 |
| **代入感** | 呼吸 / 认知 / 感知 / 身体 / 意外 / 触觉                  | 8.68 |
| **节奏**   | 长句 p90 / 短句 p10 / 段长 CV / 书面虚词                 | 8.71 |
| **句法**   | 代词密度 / 代词起句率 / 句长中位 / 转折连词 / 书面连接词 | 8.98 |

**低 AI 味 ≠ 有人味。** 干巴巴的文本可能既没有 AI 痕迹，也没有人味——两个维度要一起看。

五维卡片可点击选中，下方逐项对比会**只显示该维度覆盖的指标**。

### 逐项对比

每项给三个数：**你的分 / 标杆 / 判定**。

每个指标名旁边有一个 **`?`**：鼠标悬停即可弹出该项的**口径说明 + 原始值**；键盘按 Tab 聚焦、或触屏点按同样能打开（Esc 或再点一次收起）。

- **口径说明**只讲「数的是什么、怎么数、什么单位」，例如「含糊指代与虚写的词：在心里 / 过了很久 / 的时候。每千字。」每一条都能在 `qc_core.py` 的正则里逐字对上。
- **原始值**会带一个方向提示（如「越低越好」）。这里要区分两件事：**表里的「分」一律越高越好**，而**原始值本身有升有降**——破折号、模糊语这类是「越少越像人写的」。

判定标准：

- **达标** = 与标杆持平或更好（差距 ≤ 0.5 分）
- **接近** = 略低于标杆（差 0.5–2 分），可留意
- **偏低** = 明显低于标杆（差 > 2 分），通常是 AI 特征

因为全表统一「越高越好」，所以**没有方向栏**——不用记哪个指标是「越低越好」。

### 逐章列表

每章一行，列出**真人感 / 人味 / 代入 / 节奏 / 句法 / 总分**，命中合规硬规则时在下方附违规项。

## 评分方法

### 三层结构

```
逐项分（39 项，各 0–10）
    ↓ 该维加权平均
五维分（真人感 / 人味 / 代入感 / 节奏 / 句法，各 0–10）
    ↓ 等权平均
总分（0–10）
```

单个指标的折算只有一个公式：给每项配一对「**达标值 / 超标值**」，达标值得 **10** 分、超标值得 **0** 分，中间线性取值（`qc_core.good()`）。

这个公式**自带方向**：达标值可以大于、也可以小于超标值。所以全库不需要任何「越低越好 / 越高越好」的方向表——反向指标只要把两个阈值写反，不必改公式。

### 39 项指标

逐项对比表展示 **39 项**指标，**全部计分**。展示项与计分项完全重合——没有「展示了却不打分」的行：**无区分度的项一律直接删除**，不留在表里用 `—` 混淆视读。

维度合成用加权平均，权重只需表达相对重要性（内部按权重和归一化），因此新增指标会自动稀释原有项，不必重新配平。

### 拆章规则

单文件、文件夹与输入框文字使用**同一套**规则（前后端口径一致），支持：

| 形式         | 示例              |
| ------------ | ----------------- |
| Markdown     | `# 第一章 标题`   |
| 中文章号     | `第一章 标题`     |
| 两级章头     | `第四集 卷名 第十七章 标题`（第X集/卷/部 + 第X章，与普通章号混用时同时生效） |
| 数字序号     | `1、标题`         |
| 纯数字前缀   | `01开篇` / `02 别离` |
| 英文章号     | `Chapter 1`       |
| 特殊章节     | `楔子` / `序章` / `番外` |

单章去空白后不足 300 字的片段会被**直接丢弃**——既不单独成章，也不并入相邻章节。这个门槛用来挡掉书名页、目录行这类非正文碎片；把碎片并进相邻章节反而会污染那一章的统计。

## 基准从哪来

**内置一组预置基准值**，来自对中文长篇的逐章统计：每本全书等距抽样（单章 ≥ 1200 字，每本至多 100 章），先算各本中位，再取跨本中位。

- 基准覆盖 **24 本**。
- 基准只以**匿名代号**形式存在，**具体书目不入库**——代码、配置、文档里都不出现作品名。
- **基准只存原始指标，不存分数。** 五维分在运行时用当前公式从原始指标算出来。这样公式一改（新增指标、调整权重、撤编维度），基准口径自动跟着走，不会出现「基准是旧公式算的、被测文本是新公式算的」这种对不上的情况。

## 开发工具：全指标体检

`tools/audit.py` 是开发工具，不参与服务运行。它对全部指标逐项体检，回答「哪些指标还有效、哪些已经成了摆设」：

```bash
python3 tools/audit.py --human <真人语料> --ai <AI语料> [--ref <参照组>]
python3 tools/audit.py --human ~/books --ai ~/ai --ref ~/mine --top 20
```

- **真人组** 是判据的正样本，**AI 组** 是负样本（均可传多个路径）
- **参照组** 是已知标签的对照组，只做对照展示与误判提示，**不进任何判据**。典型用法：把自己写的正文挂上去，看它落在哪一侧
- `--top N` 打印语料体检前 N 行；`--per N` 控制每本最多抽多少章

每个指标给出四件事：**分布**、**分离度**（= 2×|AUC−0.5|，方向无关）、**残差分离度**（控制句长后，用来识破「短句化」的回声）、**两侧满分率**（≥ 95% 就是扣不动分的死项）。

### 其余开发工具

```bash
# 阈值标定：真人/AI 中位 → 建议达标线与超标线（只报告，不改源码）
python3 tools/calibrate.py --human ~/标杆文章 --ai ~/AI语料 --fp

# 重建内置基准（代号按内容指纹认领；--verify 只比对不产出）
python3 tools/bench_build.py --corpus ~/标杆文章 --verify

# 扫排版噪声：哪些指标其实在量排版（全角缩进/空行）而不是量笔法
python3 tools/layout_scan.py --human ~/标杆文章 --ai ~/AI语料

# 扫引号碎片：哪些句子类指标其实在量引号切出来的碎片而不是量笔法
python3 tools/sent_scan.py --human ~/标杆文章 --ai ~/AI语料

# 评估扩指标：把候选加进某一维，该维分离度到底是涨还是跌
python3 tools/expand_eval.py --human ~/标杆文章 --ai ~/AI语料 --fp

# 零回归：改动前后用同一批素材跑 server.analyze，逐字段比对
python3 tools/regress.py --corpus ~/语料 --per 20 --dump /tmp/base.json
python3 tools/regress.py --compare /tmp/base.json /tmp/new.json --allow redupl
```

- `calibrate.py` 的 `--fp` 只保留基准里登记过的 24 本，**标定阈值时必须开**——标杆目录里另有 5 本不可用的，不筛会把真人中位算歪。`--per` 默认 100，必须与 `bench_build.py` 的 `PERBOOK` 一致。`--ai` 可以空格连写也可以重复传，两者等价。
- `bench_build.py` 的代号靠**内容指纹**认领，不靠文件名或排序位置：目录里多一本书就会让位置式代号全体错位，而分数看起来完全正常。24 本没找齐会直接报错退出，不产出半成品。
- `layout_scan.py` 是「格式噪声必须排除」这条铁律的执行工具：它把每个指标分别在原样正文与剥掉全角缩进后的正文上算分离度，Δ 大的说明该指标在量排版。**任何新指标入库前都该先过这道扫描**——`head` 就是在这里露的馅（原样 0.92，去缩进 0.09）。同样支持 `--fp`。
- `sent_scan.py` 是同一铁律的**另一半**：`sentences()` 按 `。！？…` 切分，`“我知道了。”他点点头。` 会被切成 `“我知道了` 与 `”他点点头`，第二段的真实句首被 `”` 挡住。这类污染换字体、换缩进都消不掉，`layout_scan.py` 扫不出来，只能用本工具测。它把每个句子类指标分别在「原样切句」与「先剥掉引号字符再切句」下算分离度，Δ ≥ +0.03 的值得单独重标定。
- `expand_eval.py` 用来给「加指标」这件事**泼冷水**。往一维里加指标，每个旧指标的权重份额必然被稀释——那是算术，与好坏无关；区分度只取决于新轴的信噪比。工具会把候选按该维平均权重加进去、重算该维分离度，并跑一行**纯噪声对照**：正负号不比噪声大的候选，一律视为没有信号。**五维现在 sep 已 0.88–1.00，余量极小，多数候选都是负收益**——扩维度的价值在「换轴覆盖新失败模式」，不在提升分离度。
- 它同时报**真人侧左尾**（真人 24 本里有几本项分 <5 / <3）。这一列是 2026-09-14 补的，起因是一次翻车：**按 `sep` 配权能把某维 `sep` 抬 0.0092，同时把真人逐本最低分压低 0.20**——`sep` 只测「排序」，看不见「某类作者被整本压下去」。判据因此是三件事一起看：**`sep` 涨、残差 `sep` 不塌、左尾不恶化**。`act` 入代入感维三项全过（`sep` +0.043、左尾 4.83 → 4.95）；`enum` 退出打分同样三项全过（`sep` +0.0035、真人最低分 8.27 → 8.50、左尾从 10 本 <5 降到 0 本）。
- `regress.py` 的判据不是「输出完全一样」（那等于没改），而是**漂移全部落在 `--allow` 白名单内**。`--tree` 可以指到旧 commit 的 worktree，用同一套 harness 跑两棵树的评分核心。

## 设计取舍

### 为什么不用「AI 俗套词表」

实测过：「心中一凛 / 嘴角勾起 / 不禁 / 下意识 / 某种 / 莫名 / 眼神」这类人工罗列的「AI 高频词」**没有区分力**——真人长篇与 AI 文本的两端中位都是 0，AUC 只有 0.38–0.60。AI 不用它们，这批真人也不用了。

真正带电的是**句法统计**：代词密度、代词起句率、句长中位、转折连词与书面连接词。这几项在实测里 AUC ≥ 0.96，两端几乎不重叠。

### 为什么必须做残差检验

**「每千字」与「每百句」两种口径都可能被句长污染**：

- 「每千字」会被**短句化虚高**——AI 句子短，每千字句子就多，什么密度都跟着涨
- 「每百句」会被**句长绑架**——句子越长，每句撞上目标词的概率越高，`X/百句 ≈ 常数 × 句长`

所以候选指标入库前一律过一关：**在真人样本上做 `X ~ 句长中位` 回归，再看 AI 残差的分离度**。真信号在残差里仍然存在，句长的回声则会掉下来、甚至方向反转。

已退场的例子：`词汇多样性`（真人 / AI 完全重叠，有一篇 AI 还是全体最高）——原始值仍在后台计算供对照，不计分、不展示。

**但「方向反了」本身不是退场理由。** `动作密度` 曾以此为由退场（实测 AI 反而更高），2026-09-14 已复核回归：分离度与方向无关（`sep = 2|AUC−0.5|`，指标取反后 AUC 变 `1−AUC`），而 `good()` 的达标值本来就可以小于超标值。按取反口径入代入感维后，该维分离度 0.883 → 0.926，两群由重叠变不重叠。**把「方向错」当成「没信号」，是这套尺子上犯过的最大一类错。**

### 一个反直觉的发现

**「代入感 = 感官密度」是反的。**

AI 的叙述像一台摄像机：谁站在哪、看着什么、光落在哪，全拍下来了，人物却不说话、不评价、不惊讶。真人网文反过来，叙述里混着人物的**惊讶**（居然 / 竟然 / 没想到）与**当下反应**（忽然 / 猛地 / 愣住）——叙述者站在人物的脑子里（叙事学上叫内聚焦、自由间接引语）。

所以在这把尺子上，**感知动词与躯体词越多，越像 AI**；而「意外 / 示证」这类人物认知外露的标记，才是真人的特征。

### 边界

**这是「读感 lint」，不是「检测规避工具」。**

- 检测已知的 AI 句式与标点，目标是**读感**
- 外部 AIGC 检测平台只作参考，**不承诺通过任何检测**
- 适用范围：**中文长篇网文**。不适用于议论文 / 短篇 / 营销文案
- 阈值由小样本语料标定，**不是普适常数**；把它当参考尺，不要当判决书

## 隐私

**所有检测在本机完成，不上传任何内容。** 服务只监听 `127.0.0.1`，不访问外网，没有任何遥测。

### 改指标前必读

墨尺的指标分布在多层，**新增或删除一个指标需要同步 7 处**，漏一处就会出问题（漏补基准键会让接口直接 500）：

1. `qc_core.py` 的 `metrics()` —— 加正则与原始值
2. `qc_core.py` 的阈值表（`*_GOOD_BAD`）与权重表（`*_WEIGHTS`）
3. `qc_core.py` 的 `BENCH_LABEL` —— 中文名
4. `qc_core.py` 的 `BENCHMARKS` —— 24 本基准都要补上同一个键。**用 `tools/bench_build.py` 重建，不要手改**：手改容易只补一部分，而漏键会让接口直接 500
5. `server.py` 的 `SHOW` —— 展示清单与顺序
6. `server.py` 的 `DESC_TEXT` —— 逐项对比 `?` 的口径说明
7. `static/app.js` 的 `DIM_ITEMS_FALLBACK` 与 `index.html` / `README.md` 的项数文案

另外六条硬性要求：

- **新指标必须过残差检验**（见上文），否则大概率只是句长的回声
- **指标必须在去掉排版噪声后仍然有区分度**：真人语料段首常带全角缩进、AI 语料不带，任何会被这个差异影响的指标都是在量排版而不是量笔法。入库前用 `tools/layout_scan.py` 扫一遍
- **句子类指标必须过引号碎片检验**：凡是用到 `sentences()`（或拿 `len(ss)` 当分母）的指标，都要确认不是在量引号切出来的碎片——用 `tools/sent_scan.py` 扫一遍。同一句对话里的引号与 `。！？…` 会把一句切成两段，第二段的真实句首被 `”` 挡住
- **加指标前先量余量**：往一维里加指标会稀释所有旧指标的权重份额（算术必然），区分度只涨在新轴的独立信噪比上。先跑 `tools/expand_eval.py`，候选的 Δ 若打不过纯噪声对照，就是没有信号。**指标数量不是瓶颈——五维 sep 已 0.88–1.00**。另外，**方向不是淘汰理由**：`good()` 的达标值可大于也可小于超标值，公式自带方向；`sep = 2|AUC−0.5|` 与方向无关，指标取反即可用。「方向反了」和「没有信号」是两回事，混为一谈会误杀好指标
- **新指标必须过左尾检验**：`sep` 只测「排序」，测不出「真人侧绝对分的左尾」。**sep 低但真人 24 本全满分的是死项**（删了不救任何人）；**sep 高却把若干本真人压到 5 分以下的才是真问题**（风格税）。`tools/expand_eval.py` 的「真人<5 / <3」两列就是干这个的。反例很硬：按 `sep` 配权能把某维 `sep` 抬 0.0092，同时把真人逐本最低分压低 0.20
- **改完要跑零回归**：用同一批素材跑 `server.analyze` 前后对比，确认变更只落在预期字段，其余逐字节一致（`tools/regress.py`）

### 整轮回标定（2026-09-14 已执行）

**结论先行：42 项里 40 项标「← 需更新」，但绝不能机械套用。** 实测把 38 项建议值一次性代入，真人感维的真人逐本最低分从 8.50 砸到 **7.50**——多数项的 `over`（超标线）被收紧到 AI 中位，**等于取消原来的宽限带**，本想更准，结果更伤真人。

改走**逐项筛**：每次只改一项，判据 = **`sep` 涨 且 真人逐本最低分不降**。逐项 Δ 的分半信度 `r(Δ半A, Δ半B) = +0.672`（n=38，符号一致 29/38）——**是可靠信号，不是噪声**；问题不在真假，在大小。

**本轮采纳 10 项阈值**（`breath` 曾入选，因会让该维 `sep` 反降 0.0005 而剔除）：

| 项 | 维 | 旧 → 新 |
|---|---|---|
| `sent_p90` | 节奏 | `(65.0, 30.0)` → `(50.8, 27.0)`　**单项收益最大** |
| `simile` | 真人感 | `(1.00, 2.50)` → `(1.358, 3.724)` |
| `sent_den` | 真人感 | `(35.0, 70.0)` → `(37.89, 71.73)` |
| `dash` | 真人感 | `(0.50, 6.00)` → `(0.7568, 5.045)` |
| `dem_lit` | 真人感 | `(1.40, 0.00)` → `(1.177, 0.00)` |
| `emo` | 人味 | `(3.58, 1.62)` → `(3.665, 1.545)` |
| `redupl` | 人味 | `(5.577, 2.911)` → `(5.568, 2.854)` |
| `emo_type` | 人味 | `(5.02, 0.9195)` → `(5.016, 0.9195)` |
| `pron3` | 句法 | `(12.00, 17.50)` → `(11.11, 19.68)` |
| `pron_start` | 句法 | `(0.045, 0.080)` → `(0.03208, 0.09449)` |

**并清退代入感三弱项**：`imm_cog`（认知反应）/ `imm_perc`（感知）/ `imm_soma`（身体感受）——`sep` 只有 0.23–0.31，却各压 **7–10 本**真人到 5 分以下，权重合计占该维 23%。判据是「**`sep` 低 + 压真人**」，缺一不可。机制：三项在**真人内部互相打架**（同一本书在一项上高分、另一项上低分），加权平均后把真人侧拉平，而 AI 侧本来就在低位集中——于是维 `sep` 反被拖低。**改阈值救不了**：`sep` 是原始分布的性质，建议线只挪 0.02 级。项数 42 → **39**。

**效果（五维全部双升）**：

| 维 | `sep` | 真人逐本最低分 |
|---|---|---|
| 真人感 | 0.9877 → **0.9903** | 8.50 → 8.72 |
| 人味 | 0.9406 → **0.9419** | 4.96 → 4.98 |
| 代入感 | 0.9239 → **0.9339** | 4.95 → **5.23** |
| 节奏 | 0.9713 → **0.9799** | 5.50 → **6.21** |
| 句法 | 0.9976 → **0.9988** | 6.98 → 7.15 |
| 总分 | 1.0000 → 1.0000 | 6.97 → **7.34** |

**收益高度集中在两处**：代入感三弱项退场 + `sent_p90` 重标定，合计贡献总分增益的 **86%**；其余 9 项只多 +0.05，但它们撑起了真人感 / 人味 / 句法三维的增益（各 +0.0026 / +0.0013 / +0.0011）。

**未采纳，留档备查**：

- **27 项逐项判定为「不采纳」**。其中两个是「赚 `sep` 但压真人」的大项：`cv`（+0.0050 / **−0.42**）、`para_cv`（+0.0072 / **−0.32**）——正好印证判据。
- **八个死项**：`bold` / `tell` / `dede` / `rev` / `onomat` / `space` / `simile` / `comma_in`——真人侧 24 本全满分，清退它们不救任何人（`sep` 只 +0.0067）却要付真人最低分 −0.28 的代价。其中 `simile` 本轮另有阈值重标定，与「清退不采纳」是两件事，互不冲突。
- **AI 组口径不统一**：部分阈值的历史记录用 129 块口径、部分是 185 块（多收了两个语料目录）。本轮统一按 185 块复算，但源码注释里的 129 块数字未逐一改写，读注释时注意区分。
